## 🚀 Quick Start

### Prerequisites

Before you begin, ensure you have installed:
- **Node.js** (v18.x or higher)
- **npm** (v9.x or higher)
- **MongoDB** (v6.x or higher)
- **Git** (optional)

### 📦 Installation

#### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/ethiopia-calendar.git
cd ethiopia-calendar
```

#### 2. Backend Setup

```bash
# Navigate to backend directory
cd backend

# Install dependencies
npm install

# Create environment file
cp .env.example .env

# Edit .env with your credentials
nano .env
```

**backend/.env configuration:**
```env
# Server
PORT=5000
NODE_ENV=development

# Database
MONGODB_URI=mongodb://localhost:27017/ethiopian_calendar

# JWT
JWT_SECRET=your_super_secret_jwt_key_change_this
JWT_REFRESH_SECRET=your_super_secret_refresh_key
JWT_EXPIRE=30d

# Session
SESSION_SECRET=your_session_secret

# Google OAuth
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# Gemini AI
GEMINI_API_KEY=your_gemini_api_key

# Frontend URL
FRONTEND_URL=http://localhost:5173
```

#### 3. Frontend Setup

```bash
# Navigate to frontend directory
cd ../frontend

# Install dependencies
npm install

# Create environment file
cp .env.example .env

# Edit .env
nano .env
```

**frontend/.env configuration:**
```env
VITE_API_URL=http://localhost:5000/api
```

#### 4. Database Setup

```bash
# Start MongoDB (Ubuntu/Debian)
sudo systemctl start mongod

# Start MongoDB (macOS)
brew services start mongodb-community

# Start MongoDB (Windows - as Administrator)
net start MongoDB

# Seed the database with initial data
cd ../backend
npm run seed
```

#### 5. Run the Application

**Terminal 1 - Backend:**
```bash
cd backend
npm run dev
```

**Terminal 2 - Frontend:**
```bash
cd frontend
npm run dev
```

#### 6. Access the Application

Open your browser and navigate to:
```
http://localhost:5173
```

Default admin credentials:
- **Username**: admin
- **Password**: Admin123

### 🔌 API Endpoints

| Method | Endpoint | Description | Auth |
|--------|----------|-------------|------|
| **Auth** |
| POST | `/api/auth/register` | Register new user | Public |
| POST | `/api/auth/login` | Login user | Public |
| GET | `/api/auth/google` | Google OAuth login | Public |
| GET | `/api/auth/me` | Get current user | Private |
| POST | `/api/auth/logout` | Logout user | Private |
| **Users** |
| GET | `/api/users/profile` | Get user profile | Private |
| PUT | `/api/users/profile` | Update profile | Private |
| PUT | `/api/users/password` | Change password | Private |
| **Calendar** |
| GET | `/api/calendar/saints/:month/:day` | Get saints by date | Public |
| GET | `/api/calendar/readings/:month/:day` | Get daily readings | Public |
| GET | `/api/calendar/holidays/:year` | Get holidays by year | Public |
| POST | `/api/calendar/convert` | Convert dates | Public |
| **Quiz** |
| POST | `/api/quiz/generate` | Generate quiz | Private |
| GET | `/api/quiz/history` | Get quiz history | Private |
| POST | `/api/quiz/submit` | Submit quiz attempt | Private |
| **Chat** |
| POST | `/api/chat/groups` | Create group | Private |
| GET | `/api/chat/groups` | Get all groups | Public |
| POST | `/api/chat/:chatId/messages` | Send message | Private |
| POST | `/api/chat/:chatId/polls` | Create poll | Private |

## 🎯 Key Features in Detail

### 📅 Ethiopian Calendar System

The Ethiopian calendar is based on the ancient Coptic calendar and is approximately 7-8 years behind the Gregorian calendar. It features:
- **13 months**: 12 months of 30 days + Pagume (5 or 6 days)
- **Leap years**: Every 4th year (Ethiopian year ending with 3)
- **Ethiopian numerals**: ፩, ፪, ፫, etc. for numbers
- **Amharic month names**: መስከረም, ጥቅምት, etc.

### ⛪ Synaxarium (ስንክሳር)

Daily saints and commemorations including:
- Saint biographies in Amharic and English
- Feast days and traditions
- Miracles and iconography
- Search by date or saint name

### 📖 Daily Readings (ግጻዊ)

- Old and New Testament readings
- Amharic translations
- Bookmark favorite readings
- Add personal notes
- Audio playback support

### 🎮 Quiz System

- **15 questions** per quiz generated by Google Gemini AI
- Categories: Synaxarium, Gizae, Holidays
- Difficulty levels: Easy, Medium, Hard
- Score tracking and history
- Share quizzes in chat

### 💬 Community Chat

- **Public/Private groups** with customizable settings
- **Real-time messaging** with polling updates
- **File sharing** (images, documents)
- **Message reactions** (emojis)
- **Polls** with multiple voting options
- **Member management** (admins, moderators)
