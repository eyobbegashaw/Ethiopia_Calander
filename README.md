# Ethiopian Calendar 🇪🇹

A web-based Ethiopian calendar application that displays Ethiopian dates, holidays, and special events. This project aims to provide an easy-to-use digital calendar following the Ethiopian calendar system.

## 📋 Features

- Display Ethiopian calendar with accurate dates
- Show Ethiopian holidays and special events
- Support for Ethiopian months and date conversion
- User-friendly interface with responsive design
- JavaScript-powered interactive elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Custom Ethiopian calendar logic

## 📁 Project Structure

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of Ethiopian calendar system (optional)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/eyobbegashaw/Ethiopia_Calander.git
```

2. Navigate to the project directory:
```bash
cd Ethiopia_Calander
```

3. Open `index.html` in your web browser to view the calendar

## 📖 Usage

Simply open the `index.html` file in any modern web browser to start using the Ethiopian calendar. The application will display the current Ethiopian date and allow you to navigate through months and view holidays.

## 🎯 Features in Detail

- **Date Display**: Shows current Ethiopian date and converts between Ethiopian and Gregorian calendars
- **Holidays**: Marks Ethiopian Orthodox holidays and national celebrations
- **Navigation**: Easy navigation between months and years
- **Responsive Design**: Works on desktop and mobile devices
